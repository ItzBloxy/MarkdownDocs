MarkdownDocs 1.0 is the first public release: a desktop editor that opens Markdown files like documents and saves them back as clean, plain Markdown.

![MarkdownDocs in dark mode](https://raw.githubusercontent.com/ItzBloxy/MarkdownDocs/main/docs/screenshots/editor-dark.png)

## Highlights

- **Write in a document, keep a Markdown file.** Headings, lists, quotes, code, tables, links and images on a real page, saved as ordinary `.md`.
- **Formatting as you type.** `# `, `- `, `1. `, `**bold**`, `*italic*`, `[text](url)` and `![alt](url)` convert as you type, and `/` opens a menu of blocks to insert.
- **Images.** Insert from a web address, or upload, paste and drop them onto the page. README badges keep their links.
- **Safe with your files.** Edits files in place, reloads when another program changes them, and asks before overwriting your unsaved edits.
- **Themes.** Dark, light or match your system, with eight accent colors or any color you pick.
- **Built for Windows.** Installs with **Open with** support for `.md`, `.markdown` and `.txt`, and works fully offline.

## Downloads

| File | Use it when |
| --- | --- |
| `MarkdownDocs_1.0.0_x64-setup.exe` | You want the normal install (recommended). |
| `MarkdownDocs_1.0.0_x64_en-US.msi` | You deploy software with an MSI. |
| `MarkdownDocs_1.0.0_x64_portable.exe` | You want to run it without installing. |
| `SHA256SUMS.txt` | You want to verify your download. |

Requires 64-bit Windows 10 or 11 with the Microsoft Edge WebView2 Runtime (included in Windows 11 and current Windows 10).

> [!NOTE]
> These builds aren't code-signed yet. If Windows SmartScreen warns you, choose **More info**, then **Run anyway**.

## Known limitations

- Windows only for now. macOS and Linux can be built from source.
- Headings 4 to 6, task lists, footnotes and raw HTML open as plain text. They're saved back unchanged, just not formatted.
- There's no spellchecker in this release.
- The **Preview** mode in the shortcut list isn't available yet.
